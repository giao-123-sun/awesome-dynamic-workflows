# Research Notes

This directory contains raw agent research notes used to compile the curated lists in `data/` and `README.md`.

These files are **snapshots** taken at compilation time. They may contain:
- Unverified observations
- Time-sensitive data (star counts, project status)
- Speculative or incomplete analysis

They are provided for **transparency and traceability** — to show how entries were discovered and evaluated.

For the authoritative, maintained list, see:
- `README.md` (curated entries)
- `data/` (structured JSON and Markdown)
