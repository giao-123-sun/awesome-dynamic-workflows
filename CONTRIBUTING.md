# Contributing to Awesome Dynamic Workflows

We welcome contributions! Please follow these guidelines.

## How to Add an Entry

1. Open a pull request adding the entry to `README.md` in the appropriate category.
2. Ensure the entry includes:
   - Project name and link (GitHub or official site)
   - Short description highlighting the dynamic workflow pattern
   - License (if known)
3. If adding a new category, provide a justification.
4. Update `data/projects.json` if the project is a tool or framework.

## Quality Standards

- The project must be related to dynamic workflows for AI agents.
- Prioritize open-source projects with active maintenance.
- Include a reason why the project belongs in the list (e.g., "dynamic agent team formation", "cache-first architecture", "event-driven multi-agent").
- For research, include a link to the paper and a brief description of the approach.

## Formatting

- Use bullet points (`- **Project Name** — description...`)
- Keep descriptions concise (< 100 words).
- If the project has a notable license, mention it in parentheses.
- Use relative links for internal pages (e.g., `data/taxonomy.md`).

## Review Process

- Maintainers will review PRs for fit, quality, and formatting.
- They may request changes or clarification.
- Once approved, the entry is merged.

## Code of Conduct

Be respectful and constructive. This is a community resource.
